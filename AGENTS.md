# Repository Guidelines

## Always

Before modifying existing files/scenes, create and verify a unique timestamped backup, including unsaved Blender changes. Never overwrite backups. Preserve unrelated edits, object names, and control IDs. Use UTF-8/LF.

## Read as Needed

Read matching guides before acting; combine matches and skip unrelated guides.

- Layout, scripts, MCP, code style: [Development](docs/contributing/development.md).
- Geometry, materials, scene edits: [Blender](docs/contributing/blender.md).
- GLB export, Three.js, validation: [Export & Validation](docs/contributing/export-validation.md).
- Commits, pull requests: [Git](docs/contributing/git.md).
